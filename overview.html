Toolbar overview

Toolbar overview

All drawing and editing commands live on the toolbar down the left edge of the Pix window. The toolbar is divided into groups of related tools, each separated by a thin divider line. This page lists every group and the commands it contains.

Hover over any button to see its name, or click it to start the command. Commands shown in grey are not available in the current context.

Tip
 Commands linked below have a detailed reference page. The remaining commands work the same way — select the tool, then follow the prompts shown in the input bar at the bottom of the window.

Selection

Select entities and inspect the drawing.

  • Pick — select entities to edit

  • Info — show information about the entity under the cursor

  • Measure — measure distance and angle between points

Draw

Create lines, arcs, and points.

  • Perpendicular Line

  • Arc

  • Tangent Arc

  • Rectangle

  • Center-Point Rectangle

  • Inscribed Polygon

  • Circumscribed Polygon

  • Edge Polygon

Edit Edges

Apply corner and edge treatments for sheet-metal work.

  • Fillet

  • Chamfer

  • Inside Fillet

  • Corner Step

  • Edge Recess

  • Edge U-Cut

  • Edge V-Cut

Trim & Divide

Shorten, lengthen, or split entities.

  • Trim

  • Extend

  • Divide — split a segment into equal pieces

Construction Lines

Create temporary reference geometry to snap to. Construction lines are guides and are not part of the finished drawing.

  • Construction Line

  • Parallel Construction Line

  • Construction Circle

  • Delete Construction Lines

Modify

Transform or duplicate the current selection.

  • Move

  • Rotate

  • Scale

  • Mirror

  • Rectangular Array

  • Polar Array

Dimensions

  • Linear Dimension

  • Baseline Dimension

  • Continue Dimension

  • Angle Dimension

  • 3-Point Angle Dimension

  • Radius Dimension

  • Diameter Dimension

  • Callout Dimension

  • Segment Dimension

Bend

Add and edit sheet-metal bend lines.

  • Bend — click a line to add a bend, or a bend to edit it

Cleanup

Tidy up imported geometry and flag issues before manufacturing.

  • Join — join segments into a single polyline

  • Decurve — replace a spline with line segments

  • Remove Small Segments — delete tiny segments in a selected area

  • Mark Open Polylines — highlight contours that are not closed

  • Highlight Overlaps — find and optionally remove overlapping segments

  • Mark Non-Tangent Corners — flag corners with a slight kink

  • Mark Large Radius — flag arcs above a radius threshold

Setup

Configure the drawing environment.

  • Layer Setup — create and manage layers

  • Shift Origin — move the drawing origin
