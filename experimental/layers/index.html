Layers

Layers

Customer drawings often arrive spread across many layers - outlines, bends, dimensions, centre-mark crosshairs, text and construction geometry all mixed together. The Layers panel lets you see that structure at a glance and tame it: hide what you don’t need, lock what you must not touch, make the right layer current and move entities onto it - all while you keep drawing and watch the viewport update live.

Drawing: Base Plate 215-25-2.dxf

Opening the panel

The Layers panel docks on the right edge of the window. Open or close it with:

  • View › Layers (checkable, Ctrl+L) - the menu check mark follows the panel’s state.

  • the Layer Setup toolbar button - it now opens the same panel (the old modal dialog is gone).

Because it is a dockable panel and not a modal dialog, you can leave it open while you edit and see freeze and lock changes take effect immediately.

The layer rows

Each layer is one row, and every element on the row is clickable and acts on that layer. The current layer (the one new geometry is drawn on) is shown in bold.

  • Eye (visibility) - toggles Freeze / Thaw. An open eye means the layer is visible; a greyed, slashed eye means it is frozen. The current layer cannot be frozen.

  • Padlock (lock) - toggles Lock / Unlock. A closed padlock means locked, an open one unlocked.

  • Colour swatch - opens the edit dialog to change the layer’s name and colour.

  • Name - makes that layer the current layer. A frozen layer must be thawed first.

  • Right-click a row - opens a layer menu: Move selection here, Select entities on this layer and Move this layer’s entities to "0", all targeting the row you clicked.

Freeze vs. Lock - two different ideas

  • Freeze / Thaw hides the layer from the viewport (outlines and fills) and makes its entities non-selectable, so clicks and rubber-band drags fall through to the geometry underneath. Use it to get noisy layers out of the way.

  • Lock / Unlock keeps the layer drawn normally but excludes its entities from every selection - single click, rubber-band, Select All, Invert, Select Text and Select Polylines - so they cannot be moved, deleted or edited by accident. Use it to protect a layer you want to keep seeing but not change.

Header controls - act on all layers at once

The Visibility and Lock column headers are themselves clickable master icons:

  • Header eye - shows or hides all unlocked layers at once (it never freezes the current layer).

  • Header padlock - inverts every layer’s lock (locked layers unlock, unlocked layers lock).

The button strip

Above the list, a small strip holds the actions that are not per-row:

  • New - add a new layer (name + colour), created with a continuous line style.

  • Delete - remove the selected layer. Layer "0" and layers that still contain entities are protected; deleting the current layer first moves "current" to layer "0".

  • Purge - remove every unused (empty) layer in one step.

  • More - opens the same menu as a right-click on the selected row. Right-clicking the target layer is usually the clearer path.

Click an element to find its layer

In Pick mode, single-clicking an entity in the drawing highlights that entity’s layer row in the panel - so the panel always reflects what you just clicked. This is the fast way to answer "which layer is this on?" on an unfamiliar drawing.

Good to know

  • Freeze and lock are view state, like the current selection: they are not written to the saved file and are not on the undo stack - they are for working comfortably, not for changing the part.

  • Structural changes do undo: New, Delete, Purge, making a layer current, colour / name changes and the move-entities actions all undo and redo like any other edit.

  • Layer "0" cannot be renamed or deleted.

  • Renaming or recolouring a layer keeps its frozen and locked state.

  • Opening a new drawing automatically rebinds the panel to it.
