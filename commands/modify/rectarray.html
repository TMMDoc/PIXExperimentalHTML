Rectangular array

Rectangular array

The Rectangular array tool is used to make numerous copies of entities, and arrange them in a rectangular grid.

Using the mouse

First select the drawing entities to rotate by using the Pick tool.

Type in the Columns, Rows, and Angle values using the keyboard, and pick a reference point for the array using the mouse.

Move the mouse cursor to specify the horizontal and vertical pitch between the entities in the array, and click to create the array.

Using the keyboard

After selecting the drawing entities you want to rotate, select the Rectangular array tool.

Type in the Columns, Rows, Column pitch, Row pitch, and Angle values using the keyboard, and press Enter.

The Angle input box defines the angle of rotation for the entire array, based on the reference point specified. Positive angles rotate the array counter-clockwise, while negative angles rotate it clockwise.

Select the pick tool and click anywhere in the drawing area to deselect/exit the array command.

Pressing Enter and clicking in the drawing area before deselecting the array will continue to create multiple arrays.
