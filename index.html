Welcome to Pix

Welcome to Pix

Pix is a powerful yet intuitive 2D drawing editor specifically engineered for precision drafting and sheet metal design. Combining the accuracy required for professional engineering work with an approachable user interface, Pix empowers designers, engineers, and fabricators to create detailed technical drawings efficiently.

Introduction video

Pix application that specializes in:

  • Precision 2D Drafting: Create accurate technical drawings with exact dimensions and geometric relationships

  • Sheet Metal Design: Purpose-built tools for designing parts that will be cut, bent, and formed from sheet metal

  • 3D Modeling: Visualize your designs in three dimensions for better understanding and presentation

  • Lightweight Performance: Fast and responsive, designed to run efficiently without requiring high-end hardware

Key Features

Core Drawing Tools

Pix provides a comprehensive set of drawing commands that cover all essential geometric shapes and operations:

  • Basic Geometry: Lines, circles, arcs, rectangles, and points with precise coordinate input

  • Advanced Shapes: Polygons (inscribed and circumscribed), polar arrays, and rectangular arrays

  • Modification Tools: Fillet, chamfer, mirror, rotate, scale, and move operations

  • Specialized Features: Corner steps, edge recesses, U-edges, V-notches, and key slots for sheet metal work

Precision and Control

  • Coordinate System: Work with absolute coordinates, relative positioning, and polar coordinates

  • Snap and Grid: Intelligent snapping to grid points, object endpoints, midpoints, and intersections

  • Dimensional Accuracy: Enter exact measurements and angles for professional-grade precision

  • Constraint-Based Design: Create relationships between geometric elements that maintain design intent

Sheet Metal Specialization

Pix includes specialized tools designed specifically for sheet metal fabrication:

  • Corner Operations: Automated corner steps and edge treatments

  • Notching Tools: V-notches and edge recesses for proper material flow

  • Key Slots: Precision slots for mechanical connections

  • Bend Allowances: Built-in understanding of material properties and bending requirements
